**Pick one download:**
- **Windows, English and Spanish:** `WorshipUI-Setup-*.exe`, with the English/Español switch, Spanish lyrics and the offline lyric translator.
- **Windows, English only:** `WorshipUI-English-Setup-*.exe`, a smaller download for English-only churches.
- **Mac, English and Spanish:** `WorshipUI-*-mac.dmg`, for Intel and Apple Silicon Macs.

**Windows:** run the installer. If Windows says it protected your PC, choose **More info → Run anyway**.

**Mac:** open the .dmg and drag WorshipUI to Applications. The first time, open it, choose **Done**, then go to **System Settings → Privacy & Security → Open Anyway**. If macOS says the app is damaged, run `xattr -dr com.apple.quarantine /Applications/WorshipUI.app` in Terminal.

The installers are not signed with a paid certificate, which is why the one-time approval is needed. Your setlists and songs stay in place when you install a new version.
