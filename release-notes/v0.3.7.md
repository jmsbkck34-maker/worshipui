## What's new in 0.3.7

### Translate song lyrics into Spanish
WorshipUI can now translate a song's lyrics between English and Spanish on its own. The translation happens on your computer, so it works without internet and nothing is sent anywhere.

**How to use it**

1. Add a song with **＋ Add service item** and set the type to **Song**, or select a song in your setlist and choose **Edit item**.
2. Type or paste the English lyrics. Leave a blank line between slides.
3. Choose **Translate the lyrics**. It takes a few seconds per verse. When it finishes, the Spanish lyrics appear in **Lyrics in the second language**, one block per slide.
4. **Read the Spanish through and fix anything that sounds wrong.** Machine translation can miss the meaning and won't fit the melody, so treat it as a first draft. If the publisher has an official Spanish version (often on SongSelect), paste that in instead.
5. Save the song. To keep the Spanish for next time, choose **Save song to library** too.
6. Under **Audience screens**, choose what each screen shows: **First language** (English), **Second language** (Spanish) or **Both languages** (side by side).

**Good to know**
- Markers such as `(x2)` and `[Chorus]` are kept as they are.
- Each slide's translation stays with its slide when you reorder or duplicate slides.
- If your main language is Spanish, the button translates Spanish into English instead.
- If you paste lyrics yourself, the second-language box needs the same number of blocks as the main lyrics. If the counts don't match, WorshipUI tells you.

### English-only download
This is a new, smaller Windows installer for churches that only use English. It hides the English/Español switch, the Spanish fields and the screen language choices, and leaves out the translator. Your setlists and songs carry over between versions.

### Other changes
- The Mac download builds more reliably.
