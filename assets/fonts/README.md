# Included fonts

These unmodified fonts were obtained from the official google/fonts repository:
https://github.com/google/fonts

Inter (ofl/inter), Montserrat (ofl/montserrat), Lato (ofl/lato),
Merriweather (ofl/merriweather), Playfair Display (ofl/playfairdisplay),
Oswald (ofl/oswald), Poppins (ofl/poppins), Source Sans 3 (ofl/sourcesans3).

Each font is redistributed under its accompanying SIL Open Font License.
The individual *-OFL.txt files retain the original copyright notices and license.
Variable upright fonts are used where available, otherwise the Regular face.
No font is fetched from the internet at presentation time.
